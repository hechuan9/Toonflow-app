# 图片生成节点

根据提示词生成图片，也可使用已有图片和文本作为参考，制作角色、场景或分镜图。

## 输入与输出

- 输入支持图片和文本；连接的文本会作为生成要求的一部分。
- 输出一张生成图片，可继续用作图片或视频生成的参考。
- 张数大于 1 时逐张生成，每张结果立即保存到本节点候选组及独立文件；停止或失败时保留已完成结果。

## 使用方法

1. 选中节点，在下方选择图片模型；没有模型时先在设置中添加图片模型。
2. 输入画面要求，按需连接图片或文本参考，并在提示词中引用它们。
3. 点击比例与分辨率区域，选择当前模型提供的选项，并填写生成张数（正整数，默认 1）。
4. 点击“生成图片”；生成过程中可点击“停止生成”。
5. 收起时显示主图及图片叠层，右上角显示候选张数；点击张数展开为画布上的横向候选图。
6. 每张候选悬停或键盘聚焦后显示星标、复制到画布、下载及“设为主图”；浏览图片不改变输出，只有明确设为主图才更新下游。星标筛选不删除图片。
7. 点击图片或节点工具栏“全屏”，打开带底部缩略图的全屏查看器，支持缩略图切换、上一张／下一张、星标筛选和设为主图。
8. 点击张数旁的收起按钮显示主图，继续编辑、下载或连接下游。重新生成会追加候选，已有图片保留；批量追加保持当前选择，单张生成将新图设为输出。

参考素材可在输入区调整顺序或移除。连接的节点需要已有内容，修改提示词或设置后需再次点击生成才会产生新图片。

批量生成使用开始时的提示词、模型、尺寸和参考图，逐张提交请求。画布保持打开时队列继续运行；离开或刷新节点会取消剩余任务，已生成的图片保留。

候选悬停工具栏和全屏查看器均可删除图片。删除主图时自动选择相邻的剩余候选，删除最后一张时清空输出；生成或编辑处理中暂停删除。误删后可使用独立的“撤销删除”逐次恢复；页面关闭或刷新后，该撤销记录不保留，原文件仍可从历史记录中重新选择。删除从候选组移除图片，素材文件保留以支持当前页面内“撤销删除”及其他节点引用；不会物理擦除磁盘文件。
