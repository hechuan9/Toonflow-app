# 图片生成节点

根据提示词生成图片，也可使用已有图片和文本作为参考，制作角色、场景或分镜图。

## 使用方法

1. 选中节点，在下方选择图片模型，输入提示词，按需连接图片或文本参考。
2. 在图片生成设置中选择分辨率、比例和张数（正整数，默认 1），点击生成；多张逐张排队执行。
3. 画布始终显示主图叠层和候选张数，不横向展开。双击图片进入全屏，也可用节点工具栏的全屏按钮。
4. 全屏底部缩略图或上一张／下一张用于浏览候选；浏览不会改变输出。点击“设为主图”后，下游连线使用该图片。
5. 全屏内可下载当前图片、星标筛选及删除候选。删除主图自动切换相邻候选，删除最后一张清空输出并关闭全屏。
6. “撤销删除”可在当前页面内逐次恢复候选及原主图；刷新或关闭后撤销记录不保留。素材文件仍保留以保护其他节点引用，也可通过历史记录重新选择。

重新生成会保留已有候选；批量追加保持当前主图，单张生成将新图设为主图。生成或编辑处理中暂停删除。

批量使用开始时的提示词、模型、尺寸和参考图，需保持画布打开；离开或刷新会取消剩余提交，已完成图片保留。供应商已接收的当前任务可能继续运行。
