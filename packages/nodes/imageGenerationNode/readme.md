# 图片生成节点

根据提示词生成图片，也可使用已有图片和文本作为参考，制作角色、场景或分镜图。

## 输入与输出

- 输入支持图片和文本；连接的文本会作为生成要求的一部分。
- 输出一张生成图片，可继续用作图片或视频生成的参考。
- 张数大于 1 时逐张生成，每张结果立即保存到本节点候选组及独立文件；停止或失败时保留已完成结果。

## 使用方法

1. 选中节点，在下方选择图片模型；没有模型时先在设置中添加图片模型。
2. 输入画面要求，按需连接图片或文本参考，并在提示词中引用它们。
3. 点击比例与分辨率区域，选择当前模型提供的选项，并填写生成张数（正整数，默认 1）。
4. 点击“生成图片”；生成过程中可点击“停止生成”。
5. 点击“展开候选”并排查看图片，点击满意的候选设为节点输出；后续连线使用选中图。点击“大图比较”打开更大的并排视图，各图也可单独放大。
6. 点击“收起候选”显示选中图，继续编辑、下载或连接下游。重新生成会追加候选，已有图片保留；批量追加保持当前选择，单张生成将新图设为输出。

参考素材可在输入区调整顺序或移除。连接的节点需要已有内容，修改提示词或设置后需再次点击生成才会产生新图片。

批量生成使用开始时的提示词、模型、尺寸和参考图，逐张提交请求。画布保持打开时队列继续运行；离开或刷新节点会取消剩余任务，已生成的图片保留。
